## Phase 0. 입력 확인

| 항목 | 값 | 비고 |
|---|---|---|
| 오디오 | `rettou/song.mp3` 3:34 | 보컬은 약 3:30까지 |
| 가사 타임코드 | `rettou/lines.json` 52줄, 글자 단위 | 보컬 분리 + 일본어 음성 인식 모델 강제 정렬로 이미 확보 |

| 곡 분위기 키워드 | 열등감, 공허, 그래도 이어지는 길 | 결론은 "너와 함께가 아니면 안 돼" |

| 언어 | 일본어 가사(캡션) + 한국어 번역(캡션 아래 작은 줄) | |

### 기술서와 다르게 가는 부분 (확인 필요)

1. **캡션 크기:** 기술서는 화면 높이의 2~3%를 권장합니다. 앞 버전들에서 "가사가 잘 안 보인다"는 피드백이 있었으니 **일본어 캡션 약 4%(76px), 한국어 번역 2.3%(44px)** 로 키우겠습니다. 오브젝트에 붙이는 원칙은 지킵니다.
2. **여행(로드뷰) 요소:** 기술서의 "오브젝트 릴레이"를 **"한 줄의 길"** 로 구현합니다. 화면 아래를 가로지르는 1px 지평선이 곡 내내 이어지고, 카메라는 늘 그 선을 따라 앞으로 나아갑니다(패럴랙스). 각 월드는 길 위에서 만나는 한 장소이고, 월드 사이 전환은 길이 휘거나 올라가는 카메라 틸트(M11)로 넘어갑니다.
