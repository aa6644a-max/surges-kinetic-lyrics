# ORANGE: Y2K collage version (after HeartS2Hearts "RUDE!" motion graphics)

**Rule:** one format per line. The format is chosen from the line's meaning (a phone UI, a paper object, a game screen, a sports thing).

**Materials:**
- paper with halftone dots, and giant dotted type in the background
- torn-paper photos (our painted plates, sometimes printed as halftone)
- boiling hand-drawn lines, stamped words, emoji (Noto Color Emoji, OFL)
- flat retro windows and a mouse cursor that clicks things

**Sports feel** comes from the objects and games: tickets, the team chat, a serve power meter, a bracket, a scoreboard, a replay, a test paper at timeout, match point, game set.
