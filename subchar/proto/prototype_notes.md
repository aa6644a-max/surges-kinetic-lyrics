# Sub character v4 prototype notes

## 파일

| 파일 | 역할 |
|---|---|
| `subchar/proto.html` | 페이지 셸 (폰트, 캔버스, 미리보기 바). `python subchar/build.py proto` 로 가사 데이터를 넣어 `proto_built.html` 생성 |

| `subchar/proto/lyrics.js` | 빛(팔로우 스폿, 원)과 가사 오브젝트, 글자별 등장 |

  - 브라우저: `subchar/proto_built.html` (스페이스 = 재생/정지, 슬라이더로 탐색)

- **렌더:**
  - `node work/render.mjs out/subchar_proto_v4.mp4 --page subchar/proto_built.html --audio subchar/song.mp3 --from 40.84 --to 70.10`

## 타이포그래피 위계

- **TITLE**(Black Han Sans / Dela Gothic One): 주인공, 너, 완벽해, 넌, 빛나는지, 널, you.
  - 건축물로 쓰임: 벽, 기둥, 아치, 무대 세트, 빛줄기 위 큰 글자.
- **CREDIT**(Noto Sans KR 300–500 / IBM Plex Mono): 행인 1–7, extra, I'm a sub character, 애써/있어, 안 비슷해, Just another loser, 열등감으로 찬, Tell me, I wanna be.
  - 배역표 아래, 여백, 테이프 라벨, 무대 앞 모서리, 부스 콘솔에 둠.
- **배역표 글자 크기:** 200 → 84 → 70 → … → 21px. 크기 차이 자체가 위계.
- **첫 증가:** 부스에서 ME를 발견하는 57.4–59.0s에 `meGrow`로 ME 쪽 CREDIT 글자만 ×1.0 → ×1.3. 아직 TITLE보다 훨씬 작음.
- **남는 가사:** 불린 가사는 사라지지 않고 제자리에 흐리게 남음(keep 0.35–0.9). 후렴3에서 재방문할 흔적.

## 연속성 연결 (SEE → NOTICE → FOLLOW → ARRIVE)

| 전환 | 먼저 보이는 단서 | 카메라 |

| 배역표 → 틈 | 바닥으로 새는 빛 쐐기 + "사실 지금도"가 그 빛 속에 (41s부터 화면 오른쪽) | 기울며 알아챔 → 버팀목 따라 이동 → 틈에 push |
| 틈 → 무대 | 틈 사이로 무대 조명, "완벽해" 세트 일부 | 커튼이 비트에 올라감 → pull-out reveal |
| 무대 → 부스 | 빛줄기가 화면 오른쪽 위 밖에서 들어옴 | 빛줄기 위 가사를 따라 올라감 |
| 빛줄기 → 좌석 | 아래 가장자리에 "좋아해" 좌석 계단 | 하강 → 경사를 따라 부스로 |
